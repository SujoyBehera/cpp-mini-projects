# Number Guessing Game

A simple C++ console game where the player tries to guess a randomly
generated number between 1 and 100. The program gives hints and
counts the number of attempts.

## What I Learned

- `<cstdlib>` and `<ctime>`
- `rand()` and `srand()`
- `time()`
- `srand(time(0))`
- `rand() % 100 + 1`
- Loops and conditions
- User input
- Counting attempts
