# C++ Beginner Projects

A collection of small C++ projects that I build while learning and practicing C++ programming.

The goal of this repository is to learn C++ concepts by building small projects and gradually improving them.

## Projects

### Number Guessing Game

A simple console game where the player tries to guess a randomly generated number. The program gives hints and keeps track of attempts.

**What I learned:**
- `<cstdlib>` and `<ctime>`
- `rand()`, `srand()`, and `time()`
- `srand(time(0))`
- Generating random numbers using `rand() % n + 1`
- `switch` statements
- `while` loops
- `if`, `else if`, and `else`
- User input with `cin`
- Counting attempts
- Basic game logic and control flow

### Calculator

A simple console-based calculator for performing basic arithmetic operations.

**What I learned:**
- Taking user input with `cin`
- Displaying output with `cout`
- Arithmetic operators
- Variables and data types
- `switch` statements
- Basic conditional logic
- Building a simple menu-driven program

More projects will be added as I continue learning C++.
